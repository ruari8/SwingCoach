# SwingCoach UI playground

Run `./playgrounds/ui/run.sh` from the repo root to open the native study in a
browser-mirrored iOS Simulator. Run `./playgrounds/ui/run.sh web` for the original
five web concepts at `http://127.0.0.1:8768/web/?variant=all`.

See [UI playground and browser Simulator](../../docs/UI_PLAYGROUND.md) for state
controls, local media, build requirements, mirroring the real app and cleanup.
